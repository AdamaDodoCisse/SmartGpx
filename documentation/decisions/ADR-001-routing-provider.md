# ADR-001 — Fournisseur de routing (Google Routes)

## Statut

À rédiger en Phase 2, lors de l'implémentation de `RoutingProviderInterface` et de
`GoogleRoutesProvider`. Le choix de Google Routes comme premier fournisseur est déjà acté par le
brief produit (§9) ; cette ADR documentera les détails d'implémentation (mapping
Address/Coordinates, gestion des erreurs, quotas) une fois le code écrit.
